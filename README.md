# RisuAI 메시지 알림음 조절

RisuAI 답변 완료 시 선택한 알림음을 한 번 재생하는 플러그인입니다.

현재 버전: **1.36.0** · RisuAI 플러그인 API 3.0

## 기능

- 알림음 선택 및 음량 조절
- 재생 아이콘으로 미리듣기 및 소리 활성화
- 내 음원 불러오기: 3 MiB·30초 이하
- 알림음 사용 ON/OFF 및 스위치 조작음
- GitHub에서 새 버전 확인 후 RisuAI에서 업데이트 설치

### 제공 알림음

1. RisuAI 기본 메시지음
2. 도장 · 짧게 찍기 / 스위치 · 딸깍
3. 타자 · 세 번 / 두 번
4. 종이 · 앞으로 넘기기 / 필기 · 펜
5. 내 음원 파일

## 설치 및 사용

1. [플러그인 JS 다운로드](https://raw.githubusercontent.com/zacha-log/risu-message-sound/main/risu-message-sound.js). 코드가 화면에 표시되면 파일로 저장합니다.
2. RisuAI 설정의 플러그인 관리에서 `risu-message-sound.js`를 불러옵니다.
3. 기존 버전은 교체하고 중복 설치하지 않습니다. 교체 후 RisuAI를 새로고침합니다.
4. 소리 중복을 막으려면 RisuAI 기본 메시지 알림음과 번역 완료 알림음을 끕니다.
5. 플러그인 설정에서 사용할 소리와 음량을 선택합니다.

음원과 설정 화면이 JS에 포함되어 있으므로, 사용자는 JS 파일 하나만 설치하면 됩니다.

### 소리가 나지 않을 때

- 플러그인의 알림음 사용 여부와 전체 음량을 확인합니다.
- 재생 아이콘을 한 번 눌러 미리듣기 및 소리 활성화를 시도합니다. 앱의 자동 재생 정책에 따라 이 과정이 필요할 수 있습니다.
- 답변 완료 후 재생 진단의 수신 횟수와 오류 문구를 확인합니다.

실제 Mac 로컬 RisuAI의 성능 및 모든 환경에서의 자동 활성화는 별도 검증이 필요합니다.

## 업데이트

업데이트 주소가 없는 구버전 사용자는 이 버전의 JS로 처음 한 번 직접 교체해야 합니다.
이후 RisuAI가 새 버전을 확인하면 플러그인 관리 화면에서 업데이트를 승인하여 설치할 수 있습니다.

업데이트 주소:

```text
https://raw.githubusercontent.com/zacha-log/risu-message-sound/main/risu-message-sound.js
```

배포자는 같은 `main` 브랜치의 같은 파일 경로에 수정본을 올리고 `//@version`을 올립니다. 예: `1.36.0` → `1.36.1`.
`//@name`과 `//@update-url`은 유지하며, 버전 메타데이터는 파일 맨 위에 둡니다.
