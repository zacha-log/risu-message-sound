# RisuAI 메시지 알림음 조절

현재 버전: **1.45.1** · RisuAI 플러그인 API 3.0

AI 답변 완료 시 선택한 알림음을 한 번 재생합니다.

## 기능

- 음량 조절 · 0%로 음소거
- 펼친 목록에서 음원을 누르면 선택·저장 및 미리듣기
- 선택한 음원을 다시 누르면 다시 미리듣기
- 음원 준비 중 해당 행에 점 세 개 표시
- 재생 진단은 기본 접힘 · 필요할 때 펼치기
- 미리 로딩 없이 선택한 음원 하나만 재생용 캐시에 보관
- 사용자 음원 업로드 및 별도 사용 ON/OFF 없음
- 외부 서버 요청 없이 내장 음원 재생

## 설치

1. `risu-message-sound.js`를 내려받아 RisuAI 플러그인 관리에서 불러옵니다.
2. 기존 버전은 교체하고 앱을 다시 실행합니다.
3. 중복 재생을 막으려면 RisuAI 기본 메시지 알림음과 번역 완료 알림음을 끕니다.
4. 플러그인 설정에서 음량을 조절하고 알림음을 눌러 선택합니다.

설치에는 JS 파일 하나만 필요합니다. 소리가 나지 않으면 설정에서 음원 행을 눌러 오디오를 활성화합니다. 플러그인이 활성화되어 있으면 답변 완료 알림이 동작하며, 알림을 끄려면 음량을 0%로 맞추거나 RisuAI에서 플러그인을 비활성화합니다.

## 알림음

- RisuAI 기본 메시지음
- 도장 · 짧게 찍기 / 스위치 · 딸깍
- 타자 · 세 번 / 두 번
- 종이 · 앞으로 넘기기 / 필기 · 펜

## 업데이트 배포

저장소의 `main` 브랜치 루트에 아래 네 파일을 올립니다.

- `risu-message-sound.js`
- `LICENSE`
- `CREDITS.md`
- `README.md`

새 버전을 배포할 때 같은 경로의 JS를 교체하고 `//@version`을 올립니다. `//@name`과 `//@update-url`은 유지합니다.

업데이트 주소:

```text
https://raw.githubusercontent.com/zacha-log/risu-message-sound/main/risu-message-sound.js
```

사용자는 업데이트 주소가 포함된 버전을 한 번 직접 설치해야 합니다. 이후 RisuAI의 업데이트 확인 및 설치 절차를 따릅니다.

## 메모리와 성능

선택을 바꾸면 이전 재생용 캐시를 비우며, 처음 재생할 때 음원을 준비하고 이후 재사용합니다. WAV 녹음본은 PCM 직접 변환을 사용하고 RisuAI 기본음 MP3는 브라우저 디코더를 사용합니다. 내장 음원 데이터는 JS에 남으며 준비 중 임시 메모리가 필요합니다. 기기 상태에 따라 첫 오디오 활성화나 재생 준비에 지연이 생길 수 있습니다.
